── SC07 · UNIT 1

Differentiation

Difficulty: ★★★★☆ · Prerequisites: algebra, basic limits

📌 Core concept

Differentiation finds the rate of change of a function. The derivative f′(x)f'(x)f′(x) is the instantaneous rate of change of f(x)f(x)f(x) at xxx — geometrically, the slope of the tangent line.

📋 Key formulas

Basic differentiation rules
Power rule: ddx[xn]=nxn−1\frac{d}{dx}[x^n] = nx^{n-1}dxd​[xn]=nxn−1
Product rule: ddx[uv]=u′v+uv′\frac{d}{dx}[uv] = u'v + uv'dxd​[uv]=u′v+uv′
Quotient rule: ddx[uv]=u′v−uv′v2\frac{d}{dx}\left[\frac{u}{v}\right] = \frac{u'v - uv'}{v^2}dxd​[vu​]=v2u′v−uv′​
Chain rule: dydx=dydu⋅dudx\frac{dy}{dx} = \frac{dy}{du} \cdot \frac{du}{dx}dxdy​=dudy​⋅dxdu​
Standard derivatives
ddx[sin⁡x]=cos⁡x\frac{d}{dx}[\sin x] = \cos xdxd​[sinx]=cosx
ddx[cos⁡x]=−sin⁡x\frac{d}{dx}[\cos x] = -\sin xdxd​[cosx]=−sinx
ddx[tan⁡x]=sec⁡2x\frac{d}{dx}[\tan x] = \sec^2 xdxd​[tanx]=sec2x
ddx[ex]=ex\frac{d}{dx}[e^x] = e^xdxd​[ex]=ex
ddx[ln⁡x]=1x\frac{d}{dx}[\ln x] = \dfrac{1}{x}dxd​[lnx]=x1​
ddx[ax]=axln⁡a\frac{d}{dx}[a^x] = a^x \ln adxd​[ax]=axlna

✏️ Worked examples

Example 1 — Chain rule
Differentiate y=sin⁡(3x2+1)y = \sin(3x^2 + 1)y=sin(3x2+1).
  1. Let u=3x2+1u = 3x^2 + 1u=3x2+1, so y=sin⁡uy = \sin uy=sinu.
  2. Differentiate each part: dydu=cos⁡u\dfrac{dy}{du} = \cos ududy​=cosu, dudx=6x\dfrac{du}{dx} = 6xdxdu​=6x.
  3. Apply the chain rule: dydx=cos⁡u⋅6x=6xcos⁡(3x2+1)\frac{dy}{dx} = \cos u \cdot 6x = 6x\cos(3x^2+1)dxdy​=cosu⋅6x=6xcos(3x2+1)
Example 2 — Product rule
Differentiate y=x2exy = x^2 e^xy=x2ex.
  1. Let u=x2u = x^2u=x2, v=exv = e^xv=ex, so u′=2xu' = 2xu′=2x, v′=exv' = e^xv′=ex.
  2. Apply the product rule: dydx=u′v+uv′=2xex+x2ex=xex(2+x)\frac{dy}{dx} = u'v + uv' = 2xe^x + x^2e^x = xe^x(2+x)dxdy​=u′v+uv′=2xex+x2ex=xex(2+x)

⚠️ Common mistakes

Forgetting the chain rule — differentiating a composite function without multiplying by the inner derivative, e.g. writing ddx[sin⁡(3x)]=cos⁡(3x)\frac{d}{dx}[\sin(3x)] = \cos(3x)dxd​[sin(3x)]=cos(3x) instead of 3cos⁡(3x)3\cos(3x)3cos(3x).
Wrong product rule — using (uv)′=u′v′(uv)' = u'v'(uv)′=u′v′ instead of u′v+uv′u'v + uv'u′v+uv′.
Wrong ln⁡x\ln xlnx derivative — ddx[ln⁡x]=1x\frac{d}{dx}[\ln x] = \frac{1}{x}dxd​[lnx]=x1​, not 1ln⁡x\frac{1}{\ln x}lnx1​.

❓ FAQ

What is the difference between implicit and explicit differentiation?
An explicit function can be written as y=f(x)y = f(x)y=f(x) and differentiated directly. An implicit function (e.g. x2+y2=1x^2 + y^2 = 1x2+y2=1) cannot be isolated, so you differentiate both sides with respect to xxx, applying the chain rule to any yyy terms (multiply by dydx\frac{dy}{dx}dxdy​ each time yyy appears).
What is a second derivative and what is it for?
The second derivative f′′(x)f''(x)f′′(x) is the derivative of the derivative. It describes concavity: f′′(x)>0f''(x) > 0f′′(x)>0 means concave up, f′′(x)<0f''(x) < 0f′′(x)<0 means concave down, and a point where f′′(x)=0f''(x) = 0f′′(x)=0 and the sign changes is a point of inflection.
